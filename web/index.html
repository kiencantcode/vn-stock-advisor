Button settings

Without a key, Update now opens GitHub, where you press Run workflow. To update with one click, add a GitHub key (only the repository owner can do this):

  1. Open GitHub: new fine-grained token.
  2. Choose an expiry date. Under Repository access, pick Only select repositories and choose only this repository.
  3. Under Permissions, set Actions to Read and write. Leave everything else alone.
  4. Generate it, copy it, and paste it here.

The key stays in this browser and is sent only to GitHub. Never use a key with other permissions, and don't do this on a shared computer. Other pages under the same github.io address could read a remembered key.

How to use this page

  1. It updates by itself after the market closes, around 16:30 Vietnam time, Monday to Friday. GitHub can start late.
  2. Press Update now to update sooner. It takes about 3 to 10 minutes. Press it after 15:00 to include today's close.
  3. Click a row in Ranking to see that stock's chart.

Words

80% range
The close should land here about 8 times in 10. It can be up or down.
Buy zone
About half the time, the price dips to the lower number within 5 sessions.
Take profit
Reached about 1 time in 4.
Stop loss
Reached at most about 1 time in 10.
High rank
Top 20%. Perhaps better than the other stocks, not "will go up". Neighbouring ranks mean little: small calculation differences can swap them.
High risk
Three or more days down over 6% in the last 20 sessions.
Paused
Live results show the ranking is going wrong.

Prices are in thousands of VND. These levels have not been tested as a trading plan. Not investment advice.
