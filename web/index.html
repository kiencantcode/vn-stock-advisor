Button settings

Without a key, Update now opens GitHub, where you press Run workflow. To update with one click, add a GitHub key (only the repository owner can do this):

  1. Open GitHub: new fine-grained token.
  2. Choose an expiry date. Under Repository access, pick Only select repositories and choose only this repository.
  3. Under Permissions, set Actions to Read and write. Leave everything else alone.
  4. Generate it, copy it, and paste it here.

The key stays in this browser and is sent only to GitHub. Never use a key with other permissions, and don't do this on a shared computer. Other pages under the same github.io address could read a remembered key.

How to use this page

  1. It updates by itself after the market closes, around 16:30 Vietnam time, Monday to Friday. GitHub can start late.
  2. Press Update now to update sooner. It takes about 3 to 10 minutes. Press it after 15:00 to include today's close.
  3. In My 70/30 plan, type your money in VND to see the split: 70% long-term in an index fund, 30% for the short-term model.
  4. The short-term model is paper only. Don't buy its stocks with real money until it has proved itself live.

Words: plan and 1-month ranking

E1VFVN30
A fund you buy like a stock. It follows the 30 biggest stocks on HOSE.
Paper
Pretend trading with live prices. No real money.
1-month ranking
100 of the most traded HOSE stocks, ordered by which the model thinks will do best against the others over about 20 sessions. It learns again from all known prices at every update.
Paper rules
Every 10 sessions: hold 6 stocks in equal parts, sell one only if it falls below rank 18, trade at the next session's close, 0.4% cost for a buy and sell, no buying near the ceiling price or selling near the floor price.
Odd lot
Fewer than 100 shares. Your broker must support odd-lot orders.

High risk

Paused
